# 免费试用的双重力量：先让产品被体验，再让下一步自然发生

[返回案例库](../README.md) · [English](en/C-cialdini-samples-and-gifts.md) · 原广告或案例记录及作者、发布方的叙述

- **背景**　一组互惠案例：机场送花后募捐、超市奶酪试吃、安利把 BUG 组合留在家庭试用；可乐后售彩票的研究为机制背景。
- **读者**　尚未决定捐赠的路人，以及尚不了解或未决定购买产品的潜在顾客。
- **任务**　让陌生请求获得回应；在商业场景中让顾客先接触商品，再决定是否购买。
- **渠道**　面对面接触、超市试吃、家庭上门试用及回访。

## 原材料里看到什么

- PDF 48–50：作者转述雷根的研究。两人表面上评画，助手在休息时给参与者带可乐或空手回来，之后请其购买彩票；书称接受可乐者购买的彩票数为另一条件的两倍，且其与助手好感的关系不再像未收可乐组那样明显。
- PDF 51–53：克里希纳募捐者先把花或书等送给路人，拒绝收回，再提出捐款请求。作者也记述公众后来通过绕开募捐者、拒收礼物及场所提示来防范，说明接触与接受环节会被学习改变。
- PDF 55–56：试用先以了解商品为名提供少量产品，作者指出它同时是礼物。奶酪轶事由作者转引万斯·派科德《秘密的劝说者》，称印地安那州一家超市让顾客自己切片品尝，数小时售出 1000 磅。
- PDF 56–58：安利 BUG 包含多种家庭/个人护理用品，手册安排免费留家 24、48 或 72 小时，期末回访获取顾客愿买商品的订单。经销商报告有销量增长及平均购买其中一半商品的说法。

## 这段写法怎样起作用

本例真正可学的不是在文案里多加一个“送”字，而是理解“先收到什么，再被请求做什么”的顺序。机场案例把礼物放在请求之前，接受礼物使后面的捐赠从是否愿意支持一个陌生团体，部分转成是否应该回报别人；原文甚至用可乐研究解释，好感不足未必能抵消负债感。超市与安利则另有一条同样重要的路径：顾客获得直接接触商品的机会，原来只能相信卖方的话，现在可以用自己的经验判断。两条路径可能同时存在，原书材料没有把它们的贡献分离。对文案工作，建设性的迁移是先交付与购买判断有关的小块价值，再为自愿的下一步建立清楚的理由。安利实例的启发尤其具体：不是抽象赠品，而是能在家里用的产品组合、足以尝试的时间、已经约定的回访。这给写作者一个完整的序列——选择合适的人、说明值得验证的效果、引导真实使用、让对方说出适配与不适配处、再提出对应购买建议。先付出可以让关系更容易开始，但不应把回报义务当作产品价值的替代。强塞礼物和不准归还解释了原案例如何施压；用户一旦识别这种意图，也可能在接受前直接避开。因此有效的迁移是让样品在未成交时也完成一次有用的判断，并让后续请求与这次体验相连。

## 可借用的写作步骤

1. 先写出买家购买前最需要验证的一项问题，例如尺寸适配、清洁步骤或操作难度，再选择能回答它的样品或演示。
1. 领取文案同时交代内容、使用条件、费用/运费、试用期以及是否需要归还；把价值写成可观察的任务。
1. 随样品提供一张简短使用卡：在哪种场景试、观察什么、哪些结果说明适配、哪里需要咨询。
1. 在约定时间回访，先收集使用结果，再把确实适合的规格和购买/询价入口接上；保留不购买的路径。
1. 分别记录领取、实际试用、合格询盘、购买与退货；检验收到样品是否真的帮助了判断，而不是把领取人数当销售成功。

用于实际项目的结构：你正在判断的事项 → 这份样品能帮你验证什么 → 如何试与所需条件 → 试后按结果选择的下一步。需填入真实产品事实。

## 落稿后的检查

- 样品是否能在承诺时间内显示所说效果？
- 顾客不购买时，样品是否仍有实际价值？
- 免费条件是否与后续回访一致？
- 回访是否用顾客的实际体验解释推荐，而非诉诸欠人情？
- 促销数据是否区分商品件数、顾客转化率和收入？

## 迁移时注意的条件

- 适用于可试、可演示且试用能减少重要不确定性的商品；不能用无关赠品替代差异化产品价值。
- 高成本试用、长期才见效的产品或严格供应商礼品制度下，需换成合适的验证方式；本案例未测试这些情境。
- 体验差、隐藏收费、反复骚扰或被识别为强制回报时，可能损害继续沟通意愿。
- 原书旁栏的专家解读独立于作者正文；“更隐蔽地使用”未作为本库建议。
- 历史数字不预测当前项目；作者对安利公司增长的归因不等于已控制其他因素。

## 已知效果与依据

本书混合了研究转述、作者观察、第三方轶事及经销商报告。可乐组彩票购买数为另一条件两倍；奶酪“数小时 1000 磅”及 BUG“平均买其中一半商品”均按其各自来源限定保存，不合并为统一营销效果。
